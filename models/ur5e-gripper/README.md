# UR5e + simple gripper

Vendored **UR5e** visual STL meshes (BSD-3-Clause, Universal Robots) plus a **primitive** 2-finger gripper fixed on `tool0`.

- Arm meshes / kinematics: see `LICENSE` and `README-ur5e.md` (from UniversalRobots/Universal_Robots_ROS2_Description).
- Gripper geometry is approximate (box primitives) for teach-pendant demos only — not a Robotiq CAD model.
